KHUSHBU DASH ACADEMIC WEBSITE + ADMIN EDITOR

1. Open admin.html in Chrome.
2. Use Publications to add/edit/delete publications.
3. Use Team to add/edit/delete team members.
4. Use Profile to edit your name, headline, biography and links.
5. Click "Download website data" to export publications.json and team.json.
6. Put those updated JSON files in the website's data/ folder before publishing.

IMPORTANT:
The admin page is intentionally simple and works locally. It does not yet have login/security or cloud syncing.
For a live site, the next step is to connect the editor to a small database or CMS so that changes made in the admin page appear on the public website automatically.
